\chapter{Introduction}

\section{Context and Motivation}
The financial industry heavily relies on derivative products for risk management and investment strategies. While analytical formulas like the Black-Scholes model exist for standard European options, pricing more complex or path-dependent derivatives often requires numerical methods. The Monte Carlo simulation is a highly flexible and robust approach for option pricing, but its computational intensity can be a significant bottleneck, especially when implemented purely in interpreted languages like Python. This project is motivated by the need to solve this computational inefficiency without sacrificing usability.

\section{Project Objectives}

\subsection{Analytical Objective}
The primary analytical goal is to accurately model financial asset price dynamics using stochastic calculus. Specifically, the project implements Stochastic Differential Equations (SDEs), such as the Geometric Brownian Motion (GBM), to simulate underlying asset paths and compute the expected discounted payoff of various options under a risk-neutral measure.

\subsection{Engineering Objective}
The main engineering goal is to design a high-performance hybrid software architecture. By delegating the computationally intensive Monte Carlo simulation loops to a compiled C++ backend and exposing a user-friendly Python API via Pybind11, the system overcomes the latency limitations of Python. This approach ensures raw execution speed while maintaining ease of use for end-users and data scientists.
